# ギアスクワッド（3D・ブラウザ・試作）

ギアを使い分けて戦う、市街地の3対3チーム戦の試作。
ゲーム名・ギア名・用語はすべてオリジナル（既存作品の固有名詞は使わない）。

```bash
node server.mjs          # http://localhost:5180 で遊ぶ（PORT=5185 node server.mjs で変更可）
node test.mjs            # ロジック78項目（以前の小さい街・固定の出撃位置で回す）
node sim.mjs 300         # CPU同士で試合を回す。初接触までの時間・勝率・決着時間・膠着・めり込み
node shot.mjs fight      # 1シーンだけ撮る（title/play/fight/shoot/pad/hop/wall/bail/over/spectate/respawn/overtime/warn/ping/street/scale/meteora/hound/tele/cham/lowen/sky/
                         #   snipe-charge/snipe-shot/snipe-enemy/chars/chars-back、390x844 webkit、storm/snow で天候）
node playtest.mjs 100    # 実時間・本物のキー入力で1試合（webkit / sniper / nolook も可）→ 検証/playtest/
```

## 遊ぶ

https://tmk4men.github.io/gear-squad/ （PC・スマホのブラウザ）

## ルール

- 5分、撃破1点。時間切れで多い隊の勝ち、同点なら延長戦。強制帰還しても8秒で再出撃（2秒無敵）
- ギアは4枠。近接・銃・狙撃は1つずつ。攻撃用は試合中に武器スロットで持ち替え（1〜3／ホイール／右クリック、スマホは持ち替えボタン）。補助は専用キー
  - 近接: ブロードセイバー（22）/ スティンガー（14・速い）
  - 銃: ハンドガン（動いても正確・頭1.5倍）/ アサルトライフル（連射・撃つほど散る・撃つ間は足が重い）/ ショットガン（近距離で押し返しよろめかせる）/ グレネード（弧を描いて爆発・建物に強い）
  - 弾（銃に1種込める・枠は使わない）: 通常 / 追尾 / 炸裂 / 曲射 / 重り（当たった数だけ足とジャンプが重くなる・1分）
  - 狙撃（射程160m・画面中央の照準の先へ飛ぶ）: ロングショット / ラピッドショット / ヘビーショット
  - 補助: エアステップ（着地まで2回）/ ステルスマント / ミラージュ（4mより遠いと見えない）/ ブリンク（20m）
- ステータス4種（機動・EN量・攻撃・跳躍）に12点。レベル（試合の経験値）で最大+3点。見た目（ヘルメット・戦闘服・バイザーの光）を変えられる
- ステージ: 市街地（高層ビルは壁のベランダを伝って登る）/ 港湾倉庫街（コンテナの高台・倉庫・岸壁）。天候3種。高さ26m以下の建物は撃つと崩れる
- 索敵: レーダー50m・目視70m。見えない敵の音がミニマップに出る。M（スマホはミニマップを押す）で全体地図

## 操作

カメラは狙っている敵を自動で追う。Q（スマホは照準ボタン）で固定を外すと、マウス・矢印キーで自由に見回せ、攻撃は画面中央の照準の先へ飛ぶ。

| | PC | スマホ |
|---|---|---|
| 移動 | WASD | 左スティック |
| 近接 | J（マウスの左＝1つ目の攻撃） | 組んだ順にボタンが並ぶ |
| 射撃 | K（マウスの右＝2つ目の攻撃） | 〃 |
| 狙撃 | L 長押し | 〃（長押し） |
| エアステップ / ステルスマント / ミラージュ / ブリンク | E / C / V / F | 〃 |
| ダッシュ | Shift | 矢印のボタン |
| ジャンプ | Space | 上矢印 |
| 狙いの固定 / 切り替え | Q / Tab | 照準ボタン |
| 視点 | マウス（クリックで固定）・矢印キー | 画面をなぞる |

## 見た目

- 街は45mごとの道路（大通り3本・路地4本）で区切った8x8の街区に、建物を自動で並べる（点対称・96棟・最小9m角）。建物は実寸（1階3.6m、上は3m／階、2階建て〜25階建て。中心ほど高層）
- 1階の出入口は幅1.8m・高さ2.3mの扉。キャラ（1.9m）・自販機（1.8m）と並べて寸法が揃う（`node shot.mjs scale`）
- 屋上は6m角の防水シートの絵を繰り返す。8階建て以上には機械室と冷却塔
- 2階から上は窓の区画の絵を全棟で使い回し、1階の店先だけ建物ごとに描く（画像の容量と描画回数を抑える。描画は1回約2ms）
- 壁の絵・路面・街の小物（電柱と電線・自販機・袖看板・雨どい・室外機）・外周・遠景は `src/city.js` で全部コードから描く。
  飾りは壁から45cm以内か屋上か場外にだけ置く（人が通る所に置くとすり抜けて見えるため）
- 空は雲が流れ、遠い街ほど霞む。キャラは役割ごとに装備が違い、胸の紋章がENで暗くなる
- キャラ: 元のロボは頭が全身の3分の1あるので、頭を隠してバイザー付きのヘルメットに替え、体を1.3倍に伸ばして身長1.9mに戻した。地は濃い戦闘服、隊の色は装甲（肩・胸・腕・すね）だけ
- 骨に付けた物の大きさは `scale.set` で上書きしない（骨の倍率の打ち消しが消えて55倍になる）。掛け算で変える

## 数値の決め方

CPU同士の試合を回して決めた（`sim.mjs`）。火力を上げると十数秒で全滅するので、
1人を倒すまでの時間が13秒だと手応えが無かったので、ブロードセイバー24・弾2.2×8発・狙撃15〜40に上げて約10秒にした。
再出撃ありで1試合の撃破は約10、初接触の中央値約58秒、引き分け約14%、両陣営ほぼ五分（100試合で46対40）。
組み方ごとの1人あたり撃破は1.1〜2.7で、極端に強いものは無い。

## 作っていて踏んだもの

- three は骨の名前のドットを落とす（`LowerArm.R` → `LowerArmR`）。名前で探すと見つからず刃が付かない
- 骨は独自の倍率を持つ。付けた物の大きさは `getWorldScale` で実測して打ち消す
- 演出のアニメ（手を振る・ダンス）は毎ステップの選び直しで即消える。試合中以外は選び直さない
- スプリッターの8発を出す位置を世界の軸でずらしていたため、南から撃つ側だけ弾が交差して当たりやすく、CPU同士で南側が56%勝っていた。
  撃つ向き基準に直し、向きで割れ方が変わらないことをテストで見ている。偏りは陣地を入れ替える・世界を90度回す実験で場所を突き止めた
- テストの前提（開始直後は撃てない待ち時間）を満たさず弾が0発のまま「同じ」と判定して通っていた。撃ったことも必ず検査する
- 計測するMacが電源につながっていないと、ブラウザ全体が30fpsに抑えられる（空のページでも31）。fpsを比べるときは電源を確認する
